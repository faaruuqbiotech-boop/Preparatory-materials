## How to Use These Materials

1. Start with Module 1 to learn GIS and QGIS basics.
2. Continue with Module 2 for terrain analysis, watershed delineation, and land-cover mapping.
3. Explore Module 3 for Google Earth Engine, satellite imagery, and environmental datasets.
4. Review Module 4 for climate science and beginner Python preparation.
5. Follow the further study materials to develop your skills.
